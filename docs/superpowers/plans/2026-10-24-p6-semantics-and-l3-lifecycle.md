## 2. 语义扩召回（ADR-0001 已采纳）

### 2.1 为什么敢开
判据是逐维度比较（见 ADR §6）：**唯一变差的是复杂度**，而它换掉的是唯一一个"没有方案"的缺口。其余维度（排序质量、隔离、可迁移性、回归风险）全都不变。

### 2.2 三条硬约束
1. **只扩召回，不排序**。向量把候选拉宽到 3×，最终顺序仍由 IDF + 锚点 + recency 决定。直接对冲 `arXiv:2610.26433` 的 AUROC 0.640 结论——向量像不像，不等于撑不撑得住。
2. **按作用域分片**。`expand()` 在算相似度**之前**就套用调用方给的 `candidateFilter`。跨工作区的向量永不照面，直接消掉 `arXiv:2610.04195` 的泄漏路径。
3. **默认关、失败即降级**。`embed()` 任何异常返回 `null`（永不抛）；调用方把 `null` 当"没有语义帮助"，而不是"没有结果"。

### 2.3 诚实的一处设计
`candidateBoost` 是**可信输入**：调用方必须先用自己的硬过滤（scope + type）筛好。所以 L3 的 boost 集永远只含 `type:workflow`，`memory_search(scope=ws_x)` 的 boost 集永远只含该 scope。这不是偷懒，是把"谁能越过滤"这件事显式化。

### 2.4 开与不开的差别
- **关**（默认）：行为与 P5 逐字节一致。
- **开**：`memory_diagnose` 显示 `语义扩展: 开（model，缓存 N 条，调用 X 次失败 Y 次）`。
- **配置了但不可用**：显示 `配置为开但不可用（…）→ 已回落纯关键词`。**不静默降级**——否则用户无法判断召回为什么变了。

开启方式（profile 的 `cordis.patch.yml`）：

```yaml
- id: dsh-memory
  config:
    embedding:
      enabled: true
      endpoint: http://127.0.0.1:8001/v1/embeddings
      model: your-embedding-model
```

## 3. L3 工作流生命周期

### 3.1 衰减公式

```
score = exp(-age / 90天) × (1 + 0.6·ln(1 + 召回次数))
score < 0.18         → expired（遗忘候选）
score < 0.36         → decaying
否则                  → active
pinned: true         → 恒为 pinned，不参与
```

### 3.2 一个被我自己的测试纠正的设计判断

我最初以为"召回次数"能把工作流救回来。测试直接否了：一个 2024 年创建、三年没被用过、历史召回 40 次的流程，`score ≈ 1e-5` —— **仍然 expired**。

这是**正确的**，也是我必须接受的：永久性来自**最近被用到**（每次 L3 注入刷新 `lastUsed`），历史计数只是小加成。若让历史计数能复活长期废弃的流程，等于让"当年试过、后来没人用"的东西永久占据召回位置——正是 `arXiv:2610.05176` 说的"虚假成功的流程变成反复使用"。

所以我改的是测试，不是公式。同时修了一个真问题：`score` 原本 `toFixed(3)`，两年期的条目会塌成 `0.000`，把真实差异抹掉；现在返回 `toPrecision(4)`，只在显示时格式化。

### 3.3 三个动作（工具的 action）

| action | 行为 |
|---|---|
| `list` | 按 score 升序（最该忘的在前），显示状态/未用天数/召回次数/是否固定 |
| `pin` / `unpin` | 设/清 `pinned`；**worker 拒绝** |
| `forget` | 先预览再执行；已固定的**拒绝**并提示先 `unpin`；移入 `.trash/workflows/` + 墓碑 |
| `sweep` | 报告全部 `expired`；带 `confirm` 才真删；固定的不动 |

所有遗忘动作的返回都写明残余：**git 历史里仍可找回**。

### 3.4 使用量记录在哪
`.kb-index/usage.jsonl`（gitignored，append-only）。不用 note frontmatter 存，因为"被召回"不是"被编辑"——为了记账去改每篇笔记，会让 vault 每轮都变脏。丢掉这个文件只会重置衰减，可接受。
